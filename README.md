Healthcare Patient Metrics Analysis 🏥📊

📌 Project Overview

Healthcare Patient Metrics Analysis is a data analysis and visualization project that explores patient-related healthcare data.

The project analyzes different patient metrics and presents the findings through interactive charts and a Streamlit dashboard.

🎯 Objectives

- Analyze patient healthcare data
- Understand patient demographics and medical conditions
- Study admission types and hospital distribution
- Analyze test results and medications
- Create meaningful visualizations
- Present the analysis through an interactive dashboard

📊 Analysis Performed

The dashboard includes visualizations for:

- Gender Distribution
- Medical Condition Distribution
- Admission Type Distribution
- Hospital Distribution
- Test Results Distribution
- Medication Distribution
- Billing Statistics

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit
- Data Analysis
- Data Visualization

🚀 How to Run the Project

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder

cd Healthcare-Patient-Metrics

3. Install required libraries

pip install pandas matplotlib streamlit

4. Run the Streamlit application

streamlit run app.py

The dashboard will open in your web browser.

📈 Project Outcome

This project demonstrates how healthcare data can be analyzed and converted into meaningful visual insights using Python and Streamlit.
